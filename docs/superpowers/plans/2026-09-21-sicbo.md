# Sic Bo im Casino Royal – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ein fünftes Royal-Spiel „Sic Bo": drei Würfel, ein Wurf, 29 Wettfelder in vier Wettarten (Klein/Groß, Summe, Einzelzahl, Triple), Quoten 1:1 bis 180:1, plus Glück auf den Wurf, Insider „Gezinkter Becher" und Achievement „Drei Gleiche".

**Architecture:** Neuer DOM-freier Block `sicbo-rules` (`SicBoRules`: Quoten, `settle`, `roll`, `peekDice`, `luckOverride`) nach `stud-rules`; neues Screen-Modul `game-sicbo` (`SicBo`, Muster von `Craps`: Chips auf Felder legen, Schnappschuss beim Wurf, `Game.beginSpin(risk)` → `Game.settle(delta, { bet: risk })`) nach `game-stud`. Die 29 Felder werden beim Mount per `h()` aus `SicBoRules.FIELDS` gebaut. Einhängen über die bestehenden Royal-Listen.

**Tech Stack:** Vanilla JS in einer Datei (`keller37.html`), Selftests `T.test/T.eq/T.ok` (Node-Runner `tests/run-selftest.mjs`, DOM-Runner `tests/dom-selftest.sh`), Headless-Chrome-Playtest `tests/playtest-story.py`, `tests/mobile-check.py`.

**Spec:** `docs/superpowers/specs/2026-09-21-sicbo-design.md`

```html
<script id="sicbo-rules">
/* ================= SIC BO – drei Würfel, ein Wurf, kompaktes Wettfeld (rein, kein DOM) ================= */
const SicBoRules = {
  BET: { MIN: 50, MAX: 2000 },
  /* Quoten (Gewinn : Einsatz); Einzelzahl je Anzahl Würfel mit der Zahl (Index 0 = kein Treffer) */
  PAY: {
    small: 1, big: 1, tripleAny: 30, triple: 180, one: [0, 1, 2, 3],
    sum: { 4: 60, 5: 30, 6: 18, 7: 12, 8: 8, 9: 6, 10: 6, 11: 6, 12: 6, 13: 8, 14: 12, 15: 18, 16: 30, 17: 60 },
  },
  /* Alle 29 Felder in Tisch-Reihenfolge: Klein, Summen 4–17, Groß, Triple 1–6, Beliebiger Triple, Einzelzahl 1–6 */
  FIELDS: ['small', ...Array.from({ length: 14 }, (_, i) => `sum${i + 4}`), 'big', ...[1, 2, 3, 4, 5, 6].map((n) => `triple${n}`), 'tripleAny', ...[1, 2, 3, 4, 5, 6].map((n) => `one${n}`)],
  roll(rng) { return [0, 1, 2].map(() => Math.floor(rng() * 6) + 1); },
  risk(bets) { return Object.values(bets).reduce((a, b) => a + b, 0); },
  /* Quote eines Felds für diesen Wurf: > 0 gewinnt (Faktor), 0 verliert. Klein/Groß verlieren bei jedem Triple. */
  odds(id, dice) {
    const P = SicBoRules.PAY;
    const sum = dice[0] + dice[1] + dice[2];
    const triple = dice[0] === dice[1] && dice[1] === dice[2];
    if (id === 'small') return !triple && sum <= 10 ? P.small : 0;
    if (id === 'big') return !triple && sum >= 11 ? P.big : 0;
    if (id === 'tripleAny') return triple ? P.tripleAny : 0;
    if (id.startsWith('triple')) return triple && dice[0] === +id.slice(6) ? P.triple : 0;
    if (id.startsWith('sum')) return sum === +id.slice(3) ? P.sum[sum] : 0;
    if (id.startsWith('one')) return P.one[dice.filter((d) => d === +id.slice(3)).length];
    return 0;
  },
  /* Nettobetrag über alle gesetzten Felder; won/lost in Tisch-Reihenfolge */
  settle(bets, dice) {
    const won = [], lost = [];
    let delta = 0;
    for (const id of SicBoRules.FIELDS) {
      const bet = bets[id] || 0;
      if (!bet) continue;
      const q = SicBoRules.odds(id, dice);
      if (q > 0) { won.push(id); delta += bet * q; } else { lost.push(id); delta -= bet; }
    }
    return { delta, won, lost, sum: dice[0] + dice[1] + dice[2], triple: dice[0] === dice[1] && dice[1] === dice[2] };
  },
  /* Gezinkter Becher: der vorab gewürfelte Wert ersetzt Würfel 1 */
  peekDice(peekDie, dice) { return peekDie == null ? dice : [peekDie, dice[1], dice[2]]; },
  /* Glück: ein verlierender Wurf wird mit luck % einmal komplett neu gewürfelt. Pech: ein gewinnender Wurf mit |luck| %. Sonst unverändert. */
  luckOverride(dice, bets, luck, rng) {
    const delta = SicBoRules.settle(bets, dice).delta;
    if (luck > 0 && delta < 0 && rng() * 100 < luck) return SicBoRules.roll(rng);
    if (luck < 0 && delta > 0 && Rules.pech(luck, rng)) return SicBoRules.roll(rng);
    return dice;
  },
};
</script>
```

- [ ] **Step 3: Block `game-sicbo` schreiben**

Direkt nach dem `</script>` des Blocks `game-stud`:

```html
<script id="game-sicbo">
/* ================= SIC BO – drei Würfel, Chips auf 29 Felder, ein Wurf entscheidet alles ================= */
const SicBo = {
  root: null, rolling: false, gen: 0, bets: {}, history: [], run: null,
  peekDie: null,   // Gezinkter Becher: vorab gewürfelter Würfel 1 (null ohne Insider)
  forceDice: null, // Dev/Test: fester Wurf [d1, d2, d3] für den nächsten Wurf
  showingResult: false, // Würfel zeigen noch das letzte Ergebnis (bis zum nächsten Chip)
  FACES: ['?', '⚀', '⚁', '⚂', '⚃', '⚄', '⚅'],
  stackText(v) { return v >= 1000 ? `${Math.round(v / 100) / 10}k` : String(v); },
  alive(gen) { return !!this.root && this.gen === gen; },
  /* Tischzustand gehört zum Spielstand: anderer State.s (Moduswechsel, Neues Spiel) → Tisch räumen */
  checkRun() { if (this.run !== State.s) { this.reset(); this.render(); } },
  reset() { this.bets = {}; this.history = []; this.run = null; },
  /* Beschriftung eines Gewinnfelds für die Statuszeile */
  fieldName(id, dice) {
    if (id === 'small') return 'Klein';
    if (id === 'big') return 'Groß';
    if (id === 'tripleAny') return `Beliebiger Triple zahlt ${SicBoRules.PAY.tripleAny}:1`;
    if (id.startsWith('triple')) return `Triple ${id.slice(6)} zahlt ${SicBoRules.PAY.triple}:1`;
    if (id.startsWith('sum')) return `Summe ${id.slice(3)} zahlt ${SicBoRules.PAY.sum[+id.slice(3)]}:1`;
    const n = +id.slice(3), k = dice.filter((d) => d === n).length;
    return `Zahl ${n} ×${k} zahlt ${k}:1`;
  },
  /* Die 29 Zellen aus SicBoRules.FIELDS bauen (Klein/Groß stehen schon im Template) */
  cell(id, label, quote) {
    return h('button', { class: 'sb-cell', 'data-bet': id }, h('b', {}, label), h('small', {}, quote), h('span', { class: 'chip-stack hidden' }, '0'));
  },
  buildTable(root) {
    const sums = qs('#sbSums', root), triples = qs('#sbTriples', root), ones = qs('#sbOnes', root);
    for (let s = 4; s <= 17; s++) sums.append(this.cell(`sum${s}`, String(s), `${SicBoRules.PAY.sum[s]}:1`));
    for (let n = 1; n <= 6; n++) triples.append(this.cell(`triple${n}`, `${n} ${n} ${n}`, `${SicBoRules.PAY.triple}:1`));
    triples.append(this.cell('tripleAny', 'BELIEBIG', `${SicBoRules.PAY.tripleAny}:1`));
    for (let n = 1; n <= 6; n++) ones.append(this.cell(`one${n}`, this.FACES[n], '1:1 · 2:1 · 3:1'));
  },
  newPeek() { this.peekDie = Perks.mods().sicboPeek ? SicBoRules.roll(Math.random)[0] : null; },
  renderDice(dice) { for (let i = 0; i < 3; i++) qs(`#sbDie${i + 1}`, this.root).textContent = this.FACES[dice[i] || 0]; },
  /* Vorschau vor dem Wurf: Würfel 1 aus dem Becher, sonst „?“ */
  renderPreview() { this.showingResult = false; this.renderDice([this.peekDie || 0, 0, 0]); },
  place(id) {
    if (this.rolling || !this.root || !SicBoRules.FIELDS.includes(id)) return;
    this.checkRun();
    const v = Game.readBet('sicBet');
    if (!(v >= SicBoRules.BET.MIN && v <= SicBoRules.BET.MAX)) { UI.toast({ icon: '🎲', title: 'Einsatz', text: `Zwischen ${UI.fmt(SicBoRules.BET.MIN)} und ${UI.fmt(SicBoRules.BET.MAX)}.`, tone: 'loss' }); return; }
    this.bets[id] = Math.min(SicBoRules.BET.MAX, (this.bets[id] || 0) + v);
    this.run = State.s;
    qsa('.sb-cell', this.root).forEach((c) => c.classList.remove('won', 'lost'));
    if (this.showingResult) this.renderPreview();
    SFX.play('chip'); this.render();
  },
  clear() {
    if (this.rolling || !this.root) return;
    this.bets = {};
    qsa('.sb-cell', this.root).forEach((c) => c.classList.remove('won', 'lost'));
    SFX.play('click'); this.render();
  },
  render() {
    if (!this.root) return;
    for (const id of SicBoRules.FIELDS) {
      const st = qs(`.sb-cell[data-bet="${id}"] .chip-stack`, this.root);
      const v = this.bets[id] || 0;
      st.textContent = this.stackText(v); st.classList.toggle('hidden', v === 0); st.classList.remove('won');
    }
    const risk = SicBoRules.risk(this.bets);
    const hint = qs('#sbPeek', this.root);
    const peek = Perks.mods().sicboPeek;
    hint.classList.toggle('hidden', !peek);
    if (peek) hint.textContent = Rules.effectiveInsider(true, risk) ? '🥤 Der erste Würfel liegt schon' : `🥤 Gezinkter Becher: wirkt bis ${UI.fmt(Rules.INSIDER_CAP)}`;
    qs('#sbHistory', this.root).textContent = this.history.slice(-6).join(' · ');
    qs('#btnSbRoll', this.root).disabled = this.rolling || risk === 0;
  },
  async roll() {
    if (this.rolling || !this.root) return;
    this.checkRun();
    /* Schnappschuss der Einsätze: abgerechnet wird genau das, was treuhänderisch abgezogen wurde */
    const bets = { ...this.bets };
    const risk = SicBoRules.risk(bets);
    if (risk === 0) { SFX.play('click'); return; }
    if (!Game.beginSpin(risk)) return;
    const run = Game.run, gen = this.gen;
    this.rolling = true; this.render();
    try {
      qsa('.sb-cell', this.root).forEach((c) => c.classList.remove('won', 'lost'));
      qsa('.die', this.root).forEach((d) => d.classList.add('rolling'));
      qs('#sbStatus', this.root).textContent = 'Die Würfel rollen…';
      SFX.loop('reelSpin', 100);
      const mods = Perks.mods();
      let dice = this.forceDice ? this.forceDice.slice() : SicBoRules.roll(Math.random);
      this.forceDice = null;
      if (Rules.effectiveInsider(mods.sicboPeek, risk)) dice = SicBoRules.peekDice(this.peekDie, dice);
      dice = SicBoRules.luckOverride(dice, bets, Rules.effectiveLuck(Rules.luck(State.s, mods), risk), Math.random);
      await wait(matchMedia('(prefers-reduced-motion: reduce)').matches ? 150 : 900);
      SFX.stop('reelSpin');
      const r = SicBoRules.settle(bets, dice);
      this.history.push(dice.join('·'));
      this.bets = {};
      this.newPeek();
      if (this.alive(gen)) {
        qsa('.die', this.root).forEach((d) => d.classList.remove('rolling'));
        this.renderDice(dice); this.showingResult = true;
        SFX.play('reelStop');
        this.render();
        /* render() blendet Stacks anhand der (jetzt leeren) Einsätze aus – für die Ergebnisanzeige mit dem Schnappschuss wieder einblenden */
        for (const id of Object.keys(bets)) {
          const cell = qs(`.sb-cell[data-bet="${id}"]`, this.root);
          const won = r.won.includes(id);
          cell.classList.add(won ? 'won' : 'lost');
          const st = qs('.chip-stack', cell); st.textContent = this.stackText(bets[id]); st.classList.remove('hidden'); st.classList.toggle('won', won);
        }
        const glyphs = dice.map((d) => this.FACES[d]).join(' ');
        const parts = r.triple ? ['Triple!'] : [];
        for (const id of r.won) parts.push(this.fieldName(id, dice));
        const cls = r.delta > 0 ? 'win' : r.delta < 0 ? 'loss' : '';
        const sign = r.delta > 0 ? '+' : r.delta < 0 ? '−' : '±';
        qs('#sbStatus', this.root).innerHTML = `${glyphs} = ${r.sum} · <span class="${cls}">${parts.length ? parts.join(' · ') : 'nichts getroffen'} (${sign}${UI.fmt(Math.abs(r.delta))})</span>`;
      }
      await Bus.emit('sicbo:result', { delta: r.delta, bet: risk, dice, sum: r.sum, triple: r.triple, won: r.won, lost: r.lost });
      await Game.settle(r.delta, { from: this.alive(gen) ? qs('.craps-table', this.root) : null, game: 'sicbo', bet: risk, run });
    } finally {
      SFX.stop('reelSpin');
      if (this.gen === gen) { this.rolling = false; if (this.root) qs('#btnSbRoll', this.root).disabled = SicBoRules.risk(this.bets) === 0; }
    }
  },
  onKey(e) { if (e.code === 'Space' && qs('#cutscene').hidden && !e.repeat) { e.preventDefault(); SicBo.roll(); } },
};

UI.register('sicbo', {
  template: 'tpl-sicbo',
  mount(root) {
    SicBo.gen++; SicBo.root = root;
    if (SicBo.run !== State.s) SicBo.reset();
    SicBo.buildTable(root);
    Game.bindBet(root, 'sicBet');
    root.addEventListener('click', (e) => { const c = e.target.closest('.sb-cell[data-bet]'); if (c) SicBo.place(c.dataset.bet); });
    qs('#btnSbClear', root).addEventListener('click', () => SicBo.clear());
    qs('#btnSbRoll', root).addEventListener('click', () => SicBo.roll());
    qs('#sbBack', root).addEventListener('click', () => { SFX.play('click'); UI.show('royal'); });
    document.addEventListener('keydown', SicBo.onKey);
    SicBo.newPeek(); SicBo.renderPreview(); SicBo.render();
  },
  unmount() { SicBo.gen++; document.removeEventListener('keydown', SicBo.onKey); SFX.stop('reelSpin'); SicBo.root = null; SicBo.rolling = false; SicBo.showingResult = false; },
});
</script>
```

Geldfluss (nicht ändern): `Game.beginSpin(risk)` bucht das Risiko ab; `Game.settle(delta, { bet: risk })` schreibt `delta + risk` gut. Ungeworfene Chips werden nie abgebucht, darum kein Forfeit beim Verlassen.
